# Make It Right

Starter Next.js frontend for the Make It Right AI-powered personal finance platform.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Create a GitHub repository.
2. Upload/push this project to the repository.
3. In Vercel, choose **New Project** and import the GitHub repository.
4. Vercel should detect Next.js automatically.
5. Deploy.

This version is a frontend prototype. The PDF upload and AI classification are simulated. To make them real, connect the UI to a backend/API and an AI/document-processing provider.
